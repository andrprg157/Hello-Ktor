# 📱 Ktor Compose Android App

This is a simple Android app built with **Jetpack Compose** that demonstrates how to use **Ktor** for making network requests (GET and POST) in a modern Android application.

## 🚀 Features

- Jetpack Compose UI
- Ktor Client integration
- GET and POST request examples
- Kotlin Coroutines for asynchronous operations

---
## 🛠 Tech Stack

- Kotlin
- Jetpack Compose
- Ktor Client (Android)
- Coroutines
